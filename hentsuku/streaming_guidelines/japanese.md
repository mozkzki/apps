# 配信・動画のガイドライン

「へんつく」（アプリとWeb体験版。以下「本ゲーム」）を遊ぶ様子は、生配信・動画・スクリーンショットで自由に公開していただけます。このページは、そのときの決まりです。

**連絡は要りません**

個人・法人を問わず、当方（mozkzki）への連絡や許可の申請なしで公開できます。

**収益化してかまいません**

動画の広告収益、投げ銭（スーパーチャットなど）、メンバーシップなど、配信サイトの仕組みによる収益化をしていただけます。

**使ってよいサイト**

YouTube、ニコニコ動画、Twitch、TikTok、X、Instagram など、どのサイトでもかまいません。

**お願い**

* 動画や配信のタイトルか説明に「へんつく」と入れてください
* よろしければ、説明に次の URL を載せてください
  * Web体験版：https://hentsuku.pages.dev
  * アプリ（App Store）：https://apps.apple.com/jp/app/id6833961117

**毎日の1面について**

毎日の1面は、その日に日本中の人が同じ盤を遊びます。答え（解く順番や、その盤でできる字）を動画や配信の中で見せるのはかまいません。

ただ、まだ遊んでいない人の目に入らないように、**タイトルとサムネイルには、その盤でできる字や、解き終わった画面を載せないでください**。「今日の盤を解きます」のように、答えが分からない書き方にしていただけると助かります。

**配信用の表示**

メニューの「配信用の表示」をオンにすると、盤に座標（A〜F、1〜6）が出て、画面の隅にゲームの名前と URL が出ます。視聴者と「C3とC4は？」のように相談しながら解くときにお使いください。

**してはいけないこと**

* 本ゲームの画像・音を切り出して、別の作品やグッズの素材にすること
* 本ゲームを自分が作ったもの、または当方の公式の配信・動画であるかのように見せること
* 改造したもの、本ゲームを真似て作ったものを、本ゲームとして公開すること
* 法令や公序良俗に反する内容、他の人の権利を侵す内容と一緒に公開すること

**そのほか**

* このガイドラインは、予告なく変えることがあります。変えたときは、このページでお知らせします
* ガイドラインに沿っていない動画・配信には、公開をやめていただくようお願いすることがあります
* 企業の広告・宣伝（PR案件）として扱う場合や、ここに書いていない使い方をしたい場合は、[お問い合わせ](https://docs.google.com/forms/d/e/1FAIpQLSfV_eOPGrD3dArMnnE3P2faVMuXxs2x-8xZtliHJrInnO8jHA/viewform) からご相談ください
